# AIRBNB HOTEL BOOKING ANALYSIS

## Project Overview
An in-depth analysis of Airbnb listings to uncover market trends, pricing patterns, and host behavior in the hospitality industry.

## Research Questions
- **Property Types:** What are the various property types available in the dataset?
- **Listing Density:** Which neighbourhood group has the highest number of listings?
- **Price Insights:** Which neighbourhood group commands the highest average prices?
- **Construction Year Impact:** Is there a correlation between the year a property was built and its price?
- **Top Hosts:** Who are the top 10 hosts based on the number of listings?
- **Host Verification:** Do hosts with verified identities receive more positive reviews?
- **Price vs Service Fee:** Is there a relationship between listing price and service fees?
- **Review Rates:** What is the average review rate, and how does it vary by neighbourhood and room type?
- **Host Availability:** Are hosts with more listings more likely to maintain higher availability year-round?

## Technologies Used

## How to Run
1. Install dependencies:  

pip install -r requirements.txt

2. Place the Airbnb dataset CSV file in the project directory.
3. Run the analysis:  

python airbnb_analysis.py

4. View results in the console and generated visualization PNG file.
